P02 Paket Lengkap
=================

Buka file HTML secara langsung di Chrome/Edge/Firefox.

Urutan:
1. Jalankan file *_rentan.html.
2. Lakukan payload sesuai LAPORAN_P02.md.
3. Ambil screenshot hasil.
4. Jalankan file *_aman.html.
5. Gunakan payload yang sama.
6. Ambil screenshot hasil sesudah patch.
7. Isi identitas pada LAPORAN_P02.md.
8. Isi/ubah Risk Register sesuai hasil dan tanggal pengumpulan.
